Mağazanızı Bağlamak 3 Adım

API bilgilerini alın

Pazaryeri satıcı panelinizdeki "Entegrasyon / API bilgileri" sayfasından anahtarlarınızı kopyalayın.

Panele girin

Entegrasyonlar sayfasında kanalı seçip bilgileri yapıştırın; panel bağlantıyı hemen test eder.
